# Sidera Visus

Website of Sidera Visus, the sound art project of Néstor Paredes Ulloa (southern Chile): field recording, soundscape composition, acousmatic production and experimental electronic music.

- `index.html` — the site (static, no build step)
- `assets/img/` — photographs, album covers and process images
- `site-body.html` — same page without the document wrapper (used for the claude.ai artifact)

To publish with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
